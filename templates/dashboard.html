Setup Guide

  1. Register as a developer in Seller Central > Apps & Services > Develop Apps
  2. Create an SP-API application and note your LWA App ID and Client Secret
  3. Create an IAM user in AWS with SP-API permissions
  4. Generate a refresh token by self-authorizing your app
  5. Copy .env.example to .env and fill in all values
  6. Restart this server and start exploring your data!
